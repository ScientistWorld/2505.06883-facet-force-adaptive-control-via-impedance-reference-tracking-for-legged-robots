# Method

FACET trains a controller to imitate a virtual impedance reference model. The
reference model is a mass-spring-damper system defined over planar body motion:
the command specifies a desired setpoint, stiffness, damping, and virtual mass,
and external forces are included in the reference dynamics. Rather than directly
tracking measured force, the controller is rewarded for matching the reference
position and velocity trajectory generated by integrating those dynamics.

The paper's key target-generation detail is temporal smoothing. At each control
step, the reference dynamics are integrated from multiple earlier states along
the robot trajectory, using starts at 8, 16, and 32 control intervals in the
past. The tracking reward averages these reference targets, balancing the
smoothness of open-loop integration with the adaptivity of closed-loop tracking.

For deployment, the paper uses a two-stage teacher-student recipe. The teacher
policy has privileged simulated information such as body velocity, external
forces, torques, contacts, and reference targets. A student policy is then
initialized from the teacher and fine-tuned with an estimator that predicts the
teacher's privileged feature from deployable observations.

This reproduction preserves the central computation at reduced scale. Instead
of Isaac Lab legged-robot training, it uses a procedural planar force-interaction
environment and implements the impedance reference model, fixed-target-velocity
command form, critical damping, and temporally smoothed reference targets. The
baselines are velocity-tracking controllers that resist perturbations with fixed
feedback gains.

## Reported Paper Settings

- Control interval: 0.02 s.
- PPO training in Isaac Lab with 4096 parallel environments.
- Teacher stage: 200 million environment steps.
- Student stage: 50 million environment steps.
- Policy MLP: three 256-unit hidden layers.
- Critic MLP: 512, 256, 256 hidden units.
- Estimator: GRU with 256 hidden units.
- Reference smoothing starts: 8, 16, and 32 control intervals in the past.
- Critical damping: `Kd = 2 * sqrt(Kp)`.

## Deviations In This Environment

The full Isaac Lab robot assets and released training code are not publicly
available in a usable form; the public repository linked by the project page is
the project website and lists the open-source codebase as a TODO. The
reproduction therefore scales the simulator down to a planar dynamics benchmark
while keeping the FACET target-generation algorithm intact.
